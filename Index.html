Tipos de Páginas Web

Páginas Estáticas

Documentos cujos conteúdos são fixos e predefinidos. O servidor web simplesmente localiza o arquivo .html e o entrega ao cliente exatamente como foi codificado, sem processamento adicional.

Exemplo Prático: A landing page (página de vendas) de um aplicativo mobile que exibe apenas as funcionalidades, prints da interface e links estáticos para download nas lojas.

Páginas Dinâmicas

Páginas renderizadas sob demanda. O servidor executa regras de negócio e geralmente consulta um banco de dados relacional (como SQL Server, MySQL) ou APIs externas para montar o HTML de forma personalizada antes de enviá-lo ao cliente.

Exemplo Prático: Um sistema de dashboard financeiro, onde os gráficos e tabelas mudam conforme o login do usuário, exibindo dados puxados em tempo real de um Data Warehouse.

Ciclo de Requisição e Resposta (Client-Server)

  1. Requisição do Cliente: O usuário interage com o navegador (ex: digita uma URL). O navegador encapsula essa ação em uma requisição HTTP/HTTPS.
  2. Resolução de DNS: O navegador consulta servidores de DNS para traduzir o domínio em um endereço IP legível para a rede.
  3. Processamento no Servidor: O servidor recebe o pacote HTTP. Caso seja uma rota dinâmica, a aplicação processa a lógica, autentica e acessa os bancos de dados necessários.
  4. Resposta do Servidor: Um pacote HTTP de resposta é montado contendo um Status Code (ex: 200 OK) e o corpo da mensagem (estruturas HTML, JSON, etc.).
  5. Renderização (Client-side): O navegador recebe a resposta, baixa os recursos associados (arquivos CSS, scripts) e renderiza a interface gráfica para o usuário final.
